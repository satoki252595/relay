# GitHub 接続

ホストの `gh` CLI をエージェントが使う方式です。
Relay は GitHub の鍵を持ちません。

## 1. ホストで認証 (1回だけ)

```sh
gh auth login
```

## 2. 接続確認

アプリのプロジェクト画面に状態が出ます:

- `GitHub: 接続OK (user)` → 使えます
- `GitHub: 未接続…` → 手順 1 を実行してください

## 3. モバイルからできること

チャットで指示するだけです。例:

- 「このプロジェクトを GitHub の新規リポジトリに push して」
- 「main にコミットして push して」
- 「リポジトリ relay-test を作って README を置いて」

実行前に内容を確認したい場合は「相談」モードで計画だけ聞けます。
危険操作 (force push・削除等) は承認ゲートが止めます。

## 注意

- 初回は小さい実験用リポジトリで試すことを推奨します
- Organization への push は `gh auth` の権限 (SSO 等) に従います
